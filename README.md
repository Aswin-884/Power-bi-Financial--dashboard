# Power-bi-Financial--dashboard
--created a financial transactions dashboard to represent key insights
:-the process typically involved data collection which is being done through kaggle.com
then cleaning the data so that accurate insights can be drawn which involved correcting syntax of data or we can say format,datatypes,etc..
removing unwanted data for better understanding and efficiency of data attributes.
proper modeling between the tables for easy calculation of data related to each different tables
proper calculation of calculated tables and measures for helping in representing key insights drawn
then finally using visualization tools available in power bi desktop this financial transactions dashboard has been created
in which there are total 7 tables + 1 measure collection named table which is created to store measures,snowflake schema is formed
between the 7 tables with mostly covered with one to many cardinanlity which is considered best case scenario in terms of relationships between tables
